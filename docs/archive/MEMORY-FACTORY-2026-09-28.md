## Формат записи

```
| YYYY-MM-DD | <решение/урок> | <почему> | <последствие> |
```

Правила: одна строка на запись; «почему» обязательно (иначе запись бесполезна через
месяц); ссылка на артефакт — если он есть. Раздел **Уроки** заполняется не по факту
успеха, а по факту ошибки или обнаруженного расхождения.
