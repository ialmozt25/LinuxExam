# База знаний проекта

Здесь фиксируются наработанные практики: как мы работаем с инструментами
(DSH, MAS, git, npm), какие ошибки встречаем и как их решаем.

## Зачем
- Не наступать на одни и те же грабли дважды
- Передавать знания в новые сессии и проекты
- Единый источник правды по «как у нас принято»

## Что здесь
- `dsh/` — работа с DeepSeek Harness (пресеты, skills, permissions)
- `mas/` — мультиагентные системы (появится позже)

## Что сюда НЕ идёт
- Решения по продукту → `.project/DECISIONS.md`
- Переиспользуемые технические паттерны → `patterns/` (появится позже)
- Состояние проекта → `.project/STATE.md`

## Формат записи
Каждая запись — отдельный .md. Структура:
Проблема → Причина → Решение → Как избежать → Проверка.
