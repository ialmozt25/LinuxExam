# C-PLAN — Center evolution (инициатива C)

Отдельный трек, не продолжение DEV-PLAN (v1.4 закрыт). Фазы C0–C3. Источник
фактов о текущем центре — `docs/C0-CENTER-AUDIT.md` (C0, коммит `0074d35`).

**C-PLAN не читается `sync.mjs` до C2.** `sync.mjs` парсит только две шапки —
`docs/FACTORY-PLAN.md` и `docs/DEV-PLAN.md` (`allPhases` = F-фазы + D-фазы).
Центр покажет C-PLAN только после расширения `sync` в C2 (третий источник
шапки). Формат шапки выше — уже машинный (плоские скаляры + inline-мапы фаз),
чтобы C2 подключил её тем же `readPlanYaml(path)` без переписывания парсера.

## Цель

Центр должен читаться за 5 секунд: сверху — Пульс из 3–4 плиток, ниже — Дела
(что требует решения, что делается, тревоги, план), всё справочное — под
`<details>`. Сегодня центр — «простыня» из 18 секций и ~879 строк разметки, где
первый экран занимает прогресс банка на 14 полос.

## Контекст

- C0 — recon: `docs/C0-CENTER-AUDIT.md` (332 строки, коммит `0074d35`).
- Итог C0: **18 секций** — 3 KEEP, 3 HUMANIZE (включая уже свёрнутый `alerts`),
  3 COLLAPSE, 10 DELETE. **4 дубликата** (главный: `log.md` дважды — «Журнал»
  и «Решения»). **7 багов** `sync.mjs` (критический — wall-clock «свежий draft»
  без VOLATILE-маркеров).
- Жаргон сконцентрирован не в каркасе, а в текстах `alerts.md` (76 строк) и
  `log.md` (15 строк): `commit pending`, `sync:check`, `exit 2`, SHA, ISO-даты.

## Решения по C0 (зафиксированы)

1. Инициатива C идёт **отдельным треком**; DEV-PLAN и FACTORY-PLAN не правятся.
2. Дизайн закрепляется как spec `029-center-redesign` (type: infra, draft); (Снято в C1-fix 29.09.2026: spec 029 переведена в approved 28.09.2026 шагом C1-close, log.md:88.)
   перевод в `approved` — шаг C1-close, отдельно.
3. Завершённые планы (F0–F5 ✅, D0–D4 ✅) не удаляются из истории, а уходят
   одной строкой-сводкой и в Справочник — DELETE касается блока на первом экране.
4. Приёмка C3 — «5-секундный тест»: капитан смотрит первый экран и отвечает,
   что происходит; бинарный критерий, не «оценка качества».
