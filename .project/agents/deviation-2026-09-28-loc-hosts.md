## Что замечено

Правка `tools/local-serve.mjs` + `docs/LOCAL-ALIASES.md` меняет **имена хостов**
`linuxexam.local` / `center.local` → `linuxexam.loc` / `center.loc`. Это не
косметический рефакторинг, а **изменение приёмочного требования spec 013**
(`.project/specs/013-local-aliases.md`, status: approved):

- spec 013, цель: «`http://linuxexam.local` → сборка приложения…, `http://center.local`
  → центр разработки» (строки 19, 37–38);
- spec 013, критерии приёмки: «`docs/LOCAL-ALIASES.md` содержит… строку hosts
  **дословно**» — строка была `127.0.0.1 linuxexam.local center.local` (строка 49);
- spec 013, превью: «Лог трёх запросов: `center.local`, `linuxexam.local`, 404»
  (строка 89).

Теперь код и инструкция противоречат approved-спеке 013. По правилу 1
(«без spec — нет задачи») изменение объёма должно было прийти спекой; правка
пришла прямым заданием капитана, что допустимо, но должна быть зафиксирована.
