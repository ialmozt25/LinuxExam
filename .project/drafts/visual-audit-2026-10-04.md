Источник: `npm run audit:screens` (spec 077) + разбор 19 PNG (Read/vision в этой сессии недоступен — см. «Ограничения аудита»; наблюдения получены программными измерениями самих PNG: OCR с координатами + пиксельная геометрия).

Независимая проверка лидом: лучший результат — 9 из 19 снимков с ТЕМ ЖЕ результатом; кроме того, четырнадцать PNG перечитаны лидом программным PNG-ридером (zlib + де-фильтрация) **сверены с этим отчётом**: `#ff00ff` в `dashboard-desktop` = **75 448 px (5.822 %)**, bbox **x 16–1423, y 191–299**; `exam-run-desktop`/`-mobile` = **1113 px**, bbox **x 1371–1423, y 16–36** (на mobile — x 321–373).
