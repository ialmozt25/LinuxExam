# DOD.md — Definition of Done для UI-задач (роль Designer)

**M6.0 Phase 4 (D4) · 2026-09-28 · роль: Designer.** Принцип фабричного DOD:
критерий без доказательства (команда + exit-код или наблюдаемый артефакт) не считается
выполненным. Этот файл **не заменяет** `.project/DOD.md` (раздел `ui`) — он уточняет его
для задач `area` из `.project/factory/CONTRACTS.md` §4.2.

## Обязательный блок (любая UI-задача)

- [ ] Задача поставлена по спеке типа `ui` (правило 1); `area`, `goal`, `target_screens`
      зафиксированы в отчёте.
- [ ] **Токены без хардкода.** В изменённых компонентах нет hex-цветов, `rgb(...)` и
      пиксельных отступов литералами — только `var(--…)`. Доказательство:
      `git diff -U0` по изменённым файлам не содержит `#[0-9a-f]{3,6}` и `\d+px`
      в стилях компонентов; в отчёте — ссылка на конкретную строку
      `src/presentation/theme/tokens.css` (требование `.project/TOKENS.md`).
- [ ] **Preview показан до коммита.** Скриншот или локальная ссылка на экран;
      для типа `ui` preview — часть приёмки, без него approve невозможен.
      Доказательство: путь к файлу preview + что на нём видно.
- [ ] **jsdom-тест на структуру DOM.** Рендер через `@testing-library/react`,
      утверждения на разметку (классы, подписи, порядок), каждое — отдельный `it`
      с русским именем. Доказательство: имя файла теста + число тестов в выводе
      `npm run test:run`.
- [ ] **a11y.** `testAccessibility(container)` (`src/test/a11y-utils.ts`) — без violations.
      Контраст проверяется отдельно (jsdom не считает colour-contrast).
- [ ] **Темы.** Обе (`data-theme="dark"` / `"light"`) не сломаны: один и тот же DOM
      проходит тесты в обоих режимах.
- [ ] **Текст интерфейса на русском** (AGENTS.md); новых английских строк нет.
- [ ] `npm run typecheck` exit 0, `npm run test:run` exit 0, `npm run build` exit 0.
- [ ] Не тронуты: `quizStore`/persist, paywall-логика, `src/data/**` (freeze, правило 6),
      `.project/contracts/*`.
- [ ] Один коммит задачи + конвергентный коммит; `npm run sync:check` exit 0;
      push — только с approve капитана (правила 3, 4, 9).

## Блок `area: tokens`

- [ ] Изменение токена — только по approve капитана (`.project/TOKENS.md`), спека типа `ui`.
- [ ] Значение изменено в каноне (`tokens.css`) **и** совпадает во всех производных
      копиях (`docs/dashboard/dashboard.css`, `docs/index.html` — если в них есть копия).
- [ ] Массовый ренейм токенов в эту задачу не входит — отдельная спека.
- [ ] Доказательство: diff `tokens.css` + сверка производных копий.

## Блок `area: component` / `area: screen`

- [ ] Ни одного нового хардкода (см. общий блок).
- [ ] Нет бизнес-логики в presentation-слое (слои не смешаны).
- [ ] Состояния экрана описаны: пусто / загрузка / ошибка — если экран их имеет.
- [ ] Доказательство: preview + jsdom-тест + a11y.

## Блок `area: a11y`

- [ ] Найденная проблема воспроизведена до правки (violations-вывод `jest-axe`) —
      иначе непонятно, что именно исправлено.
- [ ] После правки: `violations 0`; для контраста — отдельные WCAG-утверждения.
- [ ] Клавиатурная навигация и фокус проверены (вручную, с записью как именно).
- [ ] Доказательство: вывод axe до/после + ручная проверка.

## Блок `area: theme`

- [ ] Обе темы отрендерены и проверены (см. общий блок).
- [ ] Переключение темы не требует перезагрузки и не теряет состояние экрана.
- [ ] Доказательство: два preview (dark/light) + тест на переключение.

## Блок `area: center` (`docs/index.html`)

- [ ] Правка центра — **не** ручная: центр генерируется `npm run sync` (правило 7);
      правится источник (`state.json` / `sync.mjs` по спеке), затем `npm run sync`.
- [ ] Смоук на структуру центра — по спеке `010` (`docs/index.html` читается
      тестом как готовый артефакт); если теста ещё нет, это известный долг, а не «гейт глазами».
- [ ] Доказательство: `sync:check` exit 0 + preview сгенерированного центра.

## Явные стоп-сигналы (задача уходит обратно, не «дожимается»)

1. Любой гейт красный → STOP и доклад (правило 2).
2. Нет preview-скриншота → approve невозможен (DOD `ui`).
3. Требуется правка контента банка → STOP (правило 6).
4. Требуется менять persist config / paywall-логику → вне скоупа роли (контракт §4.2).
5. Задача просит «заодно» отрефакторить бизнес-логику → разделить задачи.
