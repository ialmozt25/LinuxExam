## Цель

Дать капитану **человеческие адреса без порта** для двух локальных артефактов проекта:
`http://linuxexam.local` → сборка приложения (`dist/`), `http://center.local` → центр
разработки (`docs/`). Сейчас центр открывается как локальный файл или через
`npx serve` со случайным портом, а сборка приложения — через `vite preview`; порт
приходится помнить и вводить вручную, а `file://` ломает относительные пути и
поведение браузера. После задачи оба адреса вводятся словами, без `:порт`, а
разрешение имён обеспечивает стандартный hosts-файл Windows.

Дополнительно: `localhost`/`127.0.0.1` остаются рабочим фолбэком (центр), чтобы
проверка не зависела от правки hosts и прав администратора.

## Что делать

1. Создать `tools/local-serve.mjs` — статический HTTP-сервер на **встроенных модулях
   Node** (`node:http`, `node:fs`, `node:path`, `node:url`), без зависимостей.
   Маршрутизация **по хосту** запроса:

   | `Host` | Каталог | Файл по умолчанию |
   |---|---|---|
   | `linuxexam.local` | `./dist/` | `index.html` |
   | `center.local` | `./docs/` | `index.html` |
   | `localhost`, `127.0.0.1`, прочее | `./docs/` | `docs/index.html` (фолбэк) |

2. Порт по умолчанию — **80**, переопределяется флагом `--port <n>`.
3. Функциональность: MIME для `html/js/css/json/svg/png/ico/woff2`; directory index
   `index.html`; `404` → `text/plain` с записью в лог; лог каждой строкой с полями
   `Host`, `path`, `status`, `ms`; если `dist/` пуст — предупреждение
   `run npm run build` вместо тихого 404.
4. Добавить в `package.json`: `serve:local` (порт 80) и `serve:local:8080`
   (`--port 8080`).
5. Создать `docs/LOCAL-ALIASES.md` — инструкция: правка hosts **вручную** (notepad от
   администратора), точная строка `127.0.0.1 linuxexam.local center.local`, сохранение
   без BOM/LF, `npm run build` при пустом `dist/`, запуск сервера, два адреса без порта,
   обязательный префикс `http://`, фолбэк на `.test` при конфликте с mDNS.

## Критерии приёмки

- [ ] `.project/specs/013-local-aliases.md` существует (этот файл).
- [ ] `tools/local-serve.mjs` существует, использует **только** встроенные модули Node
      (ноль записей в `dependencies`/`devDependencies`), реализует таблицу маршрутизации
      выше и флаг `--port`.
- [ ] MIME покрывает ровно перечисленные типы; неизвестное расширение отдаётся как
      `application/octet-stream`, а не падает.
- [ ] Directory index работает: `/` отдаёт `index.html` соответствующего каталога.
- [ ] 404 отдаётся как `text/plain` и логируется; лог содержит Host, path, status, ms.
- [ ] Пустой `dist/` даёт предупреждение «run npm run build», а не молчаливый 404.
- [ ] Запрос с `..` в пути **не выходит** за пределы корня маршрута (traversal
      невозможен: проверка префикса нормализованного пути).
- [ ] `package.json` содержит оба скрипта с точными именами `serve:local` и
      `serve:local:8080`.
- [ ] `docs/LOCAL-ALIASES.md` содержит все 6 шагов инструкции, строку hosts дословно,
      явное «без порта» и фолбэк `.test`.
- [ ] hosts-файл **не модифицируется** кодом: сервер его не читает и не пишет.
- [ ] Локальный smoke: сервер на `--port 8090` отвечает `200` на
      `http://localhost:8090/`, после чего процесс останавливается.
- [ ] Гейты: `npm run typecheck`, `npm run test:run`, `npm run build`, `npm run qc`,
