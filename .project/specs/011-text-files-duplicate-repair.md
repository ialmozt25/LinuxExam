## Цель

Устранить **единственную пару банка, реально пробивающую порог дублирования**:
`tf_001` ~ `tf_002` (тема `text_files`), cosine = **0.9020** при пороге DOD 0.85
(инструмент `tools/cosine.cjs`, калибровка 0.80). Пара не внесена в whitelist.

Варианты устранения (выбирает капитан при разморозке):

- **rephrase одного из двух** — предпочтительно, сохраняет покрытие темы;
- **merge** — если вопросы действительно об одном и том же механизме;
- **whitelist** — только с явным обоснованием, потому что 0.9020 получено на
  англоязычной модели поверх русского текста, а bigram Jaccard пары = 0.2250
  (не ноль, то есть текстовая общность реальна).

## Критерии приёмки

- [ ] Cosine `tf_001` ~ `tf_002` ≤ 0.85 после правки (перезамер тем же
      `tools/cosine.cjs`, а не арифметикой).
- [ ] Bigram Jaccard пары приведён в отчёте до/после как второй сигнал.
- [ ] Ровно один верный ответ на вопрос, объяснение ≤ 3 строк, ratio в пределах
      класса (`checkRatio(options, 'chars')`).
- [ ] `npm run qc` — `Fails: 0`; `npm run shuffle-bank:check` exit 0;
      `npm run typecheck` exit 0; `npm run test:run` exit 0.
- [ ] Позиции `correct` остальных вопросов темы не сдвинуты (правка одного вопроса,
      не пересборка файла).
