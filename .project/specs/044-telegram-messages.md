# Spec 044 — человекочитаемые тексты Telegram-уведомлений

## Контекст

Рекон текстов уведомлений (read-only, 2026-10-01, по следам spec 042).
Ядро `notify.mjs` текстов **не формирует**: единственный конвейер
`escapeHtml` → `truncateBytes(4096)` → `redactSecrets` → `{chat_id, text,
parse_mode:'HTML'}` (`notify.mjs:725` dry-run, `:810` send, `:919`/`:664`).
Ни префикса, ни имени события, ни эмодзи ядро не добавляет — строка целиком
приходит от вызывающего. Значит, читаемость зависит от 9 мест в 4 файлах.

Найдено: все 9 текстов без эмодзи, 8 из 9 содержат английский/жаргон,
1 дублирует название спеки. Критерий «длина > 100» **не нарушен нигде**
(максимум 78 символов).

Дубликат в закрытии спеки — не опечатка шаблона, а языковое расхождение:
`shortSpecTitle()` (`close-spec.mjs:330-334`) срезает только кириллическое
`^Спека\s+\S+\s*[—–-]\s*`, а H1 всех спек пишется латиницей
(`# Spec 042 — …`), поэтому срез не срабатывает и шаблон клеит «Спека 042» +
«Spec 042 — …».

## Цель

Каждое уведомление читается капитаном с одного взгляда: сначала результат,
потом что делать; без англицизмов и внутренних идентификаторов; ≤ 100 символов;
все с эмодзи (✅ успех, ⏳ ждём капитана, ⚠️ проблема, ℹ️ к сведению).

## Критерии приёмки

1. Все 9 текстов соответствуют колонке «стало»; каждое ≤ 100 символов.
   Короткое имя в №1 обрезается до 45 символов с «…»; regex покрывает id
   с буквенным суффиксом (`033a`) — дубликата нет. Замер по всем 22 спекам
   репозитория: ≤ 100 символов — 22/22.
2. Ни один текст не содержит `sync:check`, `exit`, `SHA`, `ok`/`failed`,
   `hard-fail`, `INTENT-CHANGED`, `MAS-прогон`, `team `; латиница остаётся
   только в именах собственных (`Telegram`, `STOP`, `Spec` в H1).
3. `notify.mjs` и `notify-config.json` не изменены (проверка: пустой diff).
4. `--dry-run` для `spec_closed`, `gate_failed`, `mas_finished` печатает
   финальные тексты (живые отправки не выполняются).
5. `npm run typecheck` = 0, `npm run test:run` = 0, `npm run sync:check` = 0.
6. `shortSpecTitle` не изменён; `git diff` не трогает `:330-334`.
