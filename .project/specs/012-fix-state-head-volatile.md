## Цель

Убрать самоссылочную зависимость гейта `sync:check` от поля `state.head`:
`npm run sync` вписывает значение `state.head` в `.project/STATE.md` и
`.project/SPEC.md` **вне** volatile-маркеров, поэтому после любого коммита, двигающего
`state.head`, побайтовое сравнение производных краснеет — и закрыть его можно только
новым коммитом, который снова двигает HEAD. Цикл не сходится.

## Диагноз

Наблюдение (Phase 2, STOP-отчёт): `sync:check` → **exit 2 устойчиво, дважды подряд**
при чистом дереве, после коммита `chore(state): converge after Phase 2`.

Механика (`.project/sync.mjs`):

1. `movesOnlySyncFiles(pinned)` (`:181`) решает, закреплять ли `head`. Он смотрит
   **весь диапазон** `${pinned}..HEAD`, а не только последний коммит. Поэтому коммит,
   тронувший любой не-sync файл (`log.md`, отчёт, спека), даёт `false` → `head`
   обновляется до текущего HEAD (`:1179`).
2. Обновлённый `head` вписывается в `STATE.md` (`:610`, `:1199`) и `SPEC.md` (`:662`)
   **без** volatile-маркеров.
3. Коммит этих производных делает HEAD = `H`, но `state.head` внутри файлов остаётся
   предыдущим значением → `--check` рендерит с новым значением → побайтовое
   расхождение → exit 2 → предложение сделать ещё один коммит → шаг 1.

Центр (`docs/index.html`) от этого защищён: таблица коммитов обёрнута маркерами
`<!--volatile:start-->` / `<!--volatile:end-->` (`:1073`). `STATE.md` / `SPEC.md` — нет.

## Что делаем

Обернуть строки с `state.head` в те же HTML-коммент-маркеры, что использует центр:

```
<!--volatile:start-->- HEAD: `<sha>`<!--volatile:end-->
```

- `sync.mjs --check`: сравнивает производные через `stripVolatile` (уже так, `:1288`) —
  участок с `head` исключается из сравнения;
- write-путь: сравнивает **точно** (`:1352`), поэтому volatile-участок по-прежнему
  перезаписывается и `STATE.md`/`SPEC.md` обновляются при каждом `sync`.

## Критерии приёмки

- [ ] `state.head` в `STATE.md` и `SPEC.md` находится **внутри** volatile-маркеров;
- [ ] `npm run sync` → `git add` → один коммит → `npm run sync:check` = **exit 0**
      (без дополнительного convergence-коммита);
- [ ] probe: не-sync коммит (`.project/probe.txt`) → `sync:check` = **exit 0**
      (самоссылочный участок игнорируется), затем откат probe;
- [ ] tamper: ручная правка `STATE.md` вне volatile-участка → `sync:check` = **exit 2**
      (реальный дрейф по-прежнему ловится), затем откат tamper → exit 0;
- [ ] `state.head` остаётся видимым (информационное поле не удалено, только исключено
      из сравнения);
- [ ] гейты: `typecheck`, `test:run`, `build`, `qc` — exit 0.
